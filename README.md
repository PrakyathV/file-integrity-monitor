# File Integrity Monitor (FIM)

A Python-based File Integrity Monitoring tool that uses SHA-256 hashing to detect unauthorized file changes across multiple user-selected directories.

## Features

- **Interactive folder selection:** Add, remove and view folders through a terminal menu.
- **Persistent configuration:** Save selected folders and monitoring intervals.
- **SHA-256 hashing:** Calculate file hashes using chunked reading.
- **Multiple baselines:** Maintain separate baselines for different folder selections.
- **Integrity verification:** Detect new, modified and deleted files.
- **Live monitoring:** Monitor filesystem events using Watchdog.
- **Periodic verification:** Perform scheduled integrity checks.
- **Event logging:** Record timestamped security events.
- **Error handling:** Handle filesystem traversal and file-reading errors.
- **Symlink protection:** Skip symbolic links during scanning.

## Requirements

- Python 3.10+
- Watchdog 6.0.0
- Linux (developed and tested)

## Installation

Clone the repository and enter the project directory.

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

### 1. Select folders

Launch the interactive folder-selection menu:

```bash
python src/fim.py --select
```

Available options:

1. Add a folder
2. Remove a folder
3. Show selected folders
4. Save and continue
5. Exit

### 2. Create a baseline

```bash
python src/fim.py --baseline
```

### 3. Check file integrity

```bash
python src/fim.py --check
```

### 4. Start continuous monitoring

```bash
python src/fim.py --monitor
```

### 5. Configure monitoring interval

```bash
python src/fim.py --monitor --interval 10
```

Press `Ctrl+C` to stop monitoring.

## Example Events

```text
[NEW] /home/user/Documents/new_file.txt

[MODIFIED] /home/user/Documents/config.txt

[DELETED] /home/user/Documents/old_file.txt

[RESTORED] /home/user/Documents/config.txt
```

The RESTORED event is generated by live monitoring when a previously modified file returns to its baseline hash.

```bash
python -m unittest discover -s tests -v
```

The project includes 18 unit tests covering hashing, directory validation, configuration handling, baseline management and file-change detection.

## Security Considerations and Limitations

- Use trusted baseline creation procedures.
- Monitor only directories you own or are authorized to monitor.
- Baselines are stored locally and are not cryptographically signed.
- An attacker with sufficient privileges could modify both monitored files and local baseline data.
- Filesystem event notifications are supplemented by periodic integrity checks.
- This is an educational security project, not a production endpoint protection solution.
